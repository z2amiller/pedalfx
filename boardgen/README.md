# boardgen

Shared code for boards whose schematic and layout are generated by a script
instead of drawn (the antenna boards: `util-AntennaVHFCenter`,
`util-Antenna772`, ...). The board's own repo keeps a thin
`tools/gen_<board>.py` (schematic: what parts, where, how wired) and
`tools/gen_<board>_board.py` (layout: placement table and routing by net);
everything that is the same for every board lives here.

| module            | runs under                                                    | what                                                                                                                                                                                                                                                                                                                     |
| ----------------- | ------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| `kisch.py`        | system python                                                 | KiCad 10 schematic writer: places library symbols (pins parsed from the `.kicad_sym`, `extends` resolved), computes pin ends for any rotation, draws wires, labels, junctions, GND and PWR_FLAG helpers. Symbol libraries are searched in the project dir, then `kicad-pedal-lib/symbols`, then the stock KiCad symbols. |
| `netcheck.py`     | system python                                                 | exports the netlist with `kicad-cli` and checks it against the generator's EXPECTED table (membership match, extra nodes fail, unlisted nets warn).                                                                                                                                                                      |
| `pcbgen.py`       | KiCad's python                                                | netlist parsing, footprint loading (project `.pretty`, `kicad-pedal-lib/footprints`, stock) with the library nickname kept in the FPID, `GenBoard` (place with side flip and orientation fixing, pads by net, tracks, vias, zones, text, rounded outline, title block, SaveBoard that restores the project file).        |
| `blank.kicad_pcb` |                                                               | header-only KiCad 10 board that `pcbnew.LoadBoard` accepts as a starting point.                                                                                                                                                                                                                                          |
| `dipole_arms.py`  | system python                                                 | dipole arm footprint text for the antenna boards; reproduces the fabbed util-Antenna1090/util-Antenna772 arms exactly, with an optional mask landing window for the castellated UHF module.                                                                                                                              |
| `dipole_nec.py`   | system python + PyNEC in a scratch venv, never KiCad's python | free-space NEC-2 dipole model with ground pours at any height.                                                                                                                                                                                                                                                           |

KiCad's python is 3.9 and has no pip, so this stays stdlib + pcbnew, with one
exception: `dipole_nec.py` needs PyNEC and numpy, which run in a separate
scratch venv, never KiCad's python. Boards import it via `sys.path` (the repos
are siblings under `~/Documents/repos`):

```python
sys.path.insert(0, str(Path(__file__).resolve().parents[2] / "pedalfx" / "boardgen"))
```

Recipe and gotchas (add first then flip, route by net, no `/` in pin names, 1.27
mm schematic grid, zone pockets around GND pads) are in the memory note
`kicad-generated-board-recipe`.
