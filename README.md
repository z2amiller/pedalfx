# pedalfx

This is my repository for publicly-available guitar pedal/effects stuff.
(Documentation, gerber files, schematics, etc)

KiCad project templates live in `template/` (symlink
`~/Documents/KiCad/10.0/template` to it). The shared DRC rules, text defaults
and the `pedal-fleet` CLI that keeps templates and boards in sync are in
`template/_fleet/`.
